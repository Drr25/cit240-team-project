1. Branch – A branch is a separate workspace where you can make changes to your code without affecting the main version.

2. Commit – A commit is a saved record of changes you made to your code, including a message explaining what you changed.

3. Push – Push means uploading your committed changes from your computer to GitHub so others can see them.

4. Review – Review means checking someone’s code to make sure it works correctly and that there are no mistakes before adding it to the main project.

5. Merge – Merge means combining changes from one branch into another branch, usually into the main branch.

6. Synchronization – Synchronization means keeping your local code and the code on GitHub updated so they have the latest changes.
