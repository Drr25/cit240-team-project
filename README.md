1. Clone the Repository

Open your terminal or command prompt and clone the repository:

git clone <repository-url>
cd cit240-team-project


2. How to Open index.html

Choose one of the following methods to view the webpage in your browser:

Method 1: File Explorer / Finder (Quickest)

Locate index.html in the VS Code Explorer panel on the left.

Right-click index.html and select Reveal in File Explorer (Windows) or Reveal in Finder (macOS).

Double-click index.html to open it in your default web browser.

Method 2: Live Server Extension (Recommended)

In VS Code, open Extensions (Ctrl+Shift+X or Cmd+Shift+X).

Search for Live Server and click Install.

Right-click index.html in the file explorer and click Open with Live Server.
